DJI's official Osmo Pocket 4P LUTs (from DJI's download center) go here locally:
- D-Log 2 to Rec.709 (.cube) -> use with --input-lut
- D-Log to Rec.709 (.cube), optional -> use with --input-lut-dlog
They are gitignored: this repo is public and they are DJI's files.
Make the repo private first if you want them stored here.
